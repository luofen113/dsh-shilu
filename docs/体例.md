## 一、历法

《DSH实录》仿《明实录》之编年体：以日为纲、以时为目。纪年用公历而存**年号**与**干支**之号。

**年号冠首，公历为主，干支为辅**：
**景和元年**，岁在**丙午**，即公历 **2026** 年。文首作「景和元年（丙午 · 2026）」之式；干支不废，系于日下，为编年之骨。

**日各系以干支**，其法有定，不必查表：

```
序号 = (JDN + 49) mod 60        # 甲子 = 0；JDN 为该日之儒略日数（取正午）
天干 = 序号 mod 10 → 甲乙丙丁戊己庚辛壬癸
地支 = 序号 mod 12 → 子丑寅卯辰巳午未申酉戌亥
```

**自检向量**（取自《DSH实录》既有之目，独立来源；改算法或改本节，先过此六条）：

| 日期 | 干支 | 序号 |
|---|---|---|
| 2026-09-10 | 丁亥 | 23 |
| 2026-09-11 | 戊子 | 24 |
| 2026-09-12 | 己丑 | 25 |
| 2026-09-13 | 庚寅 | 26 |
| 2026-09-14 | 辛卯 | 27 |
| 2026-11-23 | 辛丑 | 37 |

**朔日**：凡月首标朔，以正历。本录之「日」即公历日号（初十日 = 9 月 10 日），故**朔即公历月首**，非真农历之朔 —— 此为本录自定之简法，读者须知。

```yaml
calendar:
  era_name: 景和
  era_year: 1
  ganzhi_year: 丙午
  gregorian: 2026
  order: [era, gregorian, ganzhi]      # 年号冠首，公历为主，干支为辅
  day_rule: formula
  day_formula: "(jdn + 49) % 60"
  ganzhi_epoch: 甲子 = 0
  check_vectors:
    - { date: 2026-09-10, ganzhi: 丁亥, n: 23 }
    - { date: 2026-09-11, ganzhi: 戊子, n: 24 }
    - { date: 2026-09-12, ganzhi: 己丑, n: 25 }
    - { date: 2026-09-13, ganzhi: 庚寅, n: 26 }
    - { date: 2026-09-14, ganzhi: 辛卯, n: 27 }
    - { date: 2026-11-23, ganzhi: 辛丑, n: 37 }
  shuo:
    enabled: true
    basis: gregorian_month_start   # 本录之朔 = 公历月首
    known:
      "2026-09": 戊寅
      "2026-10": 戊申
      "2026-11": 己卯
      "2026-12": 己酉
  hour: twelve_earthly_branches        # 纪时用十二辰
```

## 二、记注之权

《DSH实录》者，**工作区总纲**也。凡动本机、改配置、立体制、得新识、遭教训者，皆当录之。

- **必录**：诏令（主上之命）、决策与其故、已做成之事（附验法）、错误与修复（附根因）、新识与教训；
- **可录**：章奏之往复、工具之结果、数字之快照；
- **不录**：临时草稿、中间态、可随时重建之物、密钥与凭据、与本机无关之琐屑。

**不妄改旧文**：技术名词、路径、数字一仍其旧；史笔所记之旧名（如「<user>」）不得以今名回改。补记则明标「追记」。

**一事一据**：凡断语必附可查之凭（哈希、行数、命令、文件路径）。

```yaml
record_policy:
  must: [诏令, 决策, 做成之事, 错误与修复, 新识教训]
  may: [章奏往复, 工具结果, 数字快照]
  never: [临时草稿, 中间态, 可重建之物, 密钥凭据, 无关琐屑]
  immutable_history: true      # 旧文不改；新名不回溯改旧名
  evidence_required: true
  late_entry_marker: 追记
```

## 三、录事之准

事之录也，必具其时、其类、其轻重、其据。**分类由执笔者定**（机器只供未加裁剪之事实，不代归类 —— 归类之轻重是执笔者的活）。

**轻重五等**：1 琐 · 2 常 · 3 要 · 4 重 · 5 关键。**密级三等**：公开 / 内部 / 机密。

```yaml
event_schema:
  ts: ISO8601                 # 事件发生之时
  ganzhi: string              # 该日干支（由 calendar.day_formula 推）
  type: enum[诏令, 章奏, 决策, 结果, 错误]
  importance: 1..5
  sensitivity: enum[公开, 内部, 机密]
  evidence: array             # 可查之凭，至少一条
  note: string

materials:
  grain: day_multi_session    # 一日 · 多会话（一日之内常有多条会话并行）
  order: chronological
  classify_by: agent          # 机器不归类
  forbid:
    - 生成日稿文件            # 无日稿这一层
    - 代写实录                # 机器不入史
    - 新注册投影单元          # 不监听事件流，那本是 chronicle 的职分
```

## 四、卷三格式

卷三为二人通信之纸：**一事一纸，署日署名**。新札附于卷末，**旧札不改**。

```yaml
handnote:
  format: short_letter
  fields: [date, to, author, subject, body, evidence]
  append_only: true
  path: F:\AI\DSH\DSH实录.md
  section_anchor: "## 卷三 · 共用手记"
  numbering: 汉字序数，逐札递增（如「第十三札」）
```

## 五、校验之则

器先自验，尺先于物：

1. 凡例读不到 / YAML 解析失败 → **单元不启用 + 告警写明行号**，绝不整进程拒启；
2. 口径副本（README、代码常量、实录）互校，跑 `rule-drift-check.mjs`；
3. 干支算法改则先过六条自检向量；
4. 写卷三先用临时目录试，逐字节比对。
