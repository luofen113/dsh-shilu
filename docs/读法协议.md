## 四、红线

1. **不妄改旧文**：技术名词、路径、数字一仍其旧；旧名（如「<user>」）不得以今名回改。
2. **改必改全链**：一处配置常有副本与派生（人设真源 → 生成脚本 → preset），改完**干跑一次**验闭环。
3. **凡验一事，独立复算**：验器先验其器；**尺子与所验之物不得共用同一批对象**（见《志余·戒慎》）。
4. **动 DSH 本体或本机者**：自主判断是否写入《DSH实录》；牵动初初职分者，另于卷三留札。
5. **含中文之 `.ps1` 必 UTF-8 with BOM**；凡以 PowerShell 数行、切行者，必加 `-Encoding UTF8`（否则吞换行）。

## 六、插件事

- 入册走正门：`dsh plugin --profile web add file:<tgz>`；**先 `pnpm pack`**（`link:`／`file:` 目录装出来的插件依赖解析不通）。
- 自带 `cordis.patch.yml` 者由 `bundles` 挂载，**profile 的 patch 里勿再写同 id 的 insert**。
- 宿主半侧插件代码、agent preset、配置树 —— 三类改动**皆须重启 `dsh web`** 方生效。
